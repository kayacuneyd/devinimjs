# v0.7.0-beta.0 release checklist

## Scope

- The fullstack-CMS roadmap round (`devinimjs-yol-haritasi.md`): application runtime
  (`createApi`, `validate`, router guards/lazy/`mount`/`dv-link`, `createI18n`, store
  `set`/`update`/`persist`, prop descriptors, `__DEVINIM_DEBUG__`), the `<dv-media-upload>`
  component and the `kits/ci4-cms/` CodeIgniter 4 + SQLite CMS starter kit.
- ADR-0021…0027 + the ADR-0011 amendment record every decision; CHANGELOG `[0.7.0-beta.0]`
  carries the per-item details and the size-budget accounting (3793 → 4065 B min+gzip,
  budget 4096 B — constitution §9).
- No breaking changes: legacy bare-default props, ADR-0012 synchronous routing and the
  class API all behave as before (covered by the unchanged pre-existing test suite).

## Publish order

1. Run `npm run build` and `npm run verify` from a clean checkout. ✅ (lint 0 problems,
   unit 283/283, e2e 36/36 chromium, size gate 4065/4096 B; `npm run build` regenerated
   `dist/` incl. `dist/modules/dv-media-upload.js`.)
2. Check the new framework component with `npm run validate:component -- dv-media-upload`. ✅
3. Review `dist/app.min.js` (application barrel: createApi/validate/router/i18n) and
   `dist/modules/dv-media-upload.js` (self-containment regression test passes).
4. Commit, tag `v0.7.0-beta.0`, push the tag and wait for CDN propagation.
5. Public CDN examples were moved from `v0.5.1`/`v0.1.0` to `v0.7.0-beta.0` in this release —
   verify a pinned URL resolves after the tag is pushed, e.g.
   `https://cdn.jsdelivr.net/gh/kayacuneyd/devinimjs@v0.7.0-beta.0/dist/core.min.js`.
6. `kits/ci4-cms/` is a PHP overlay (no `create-project` wiring): smoke-test its README
   install path on a stock `codeigniter4/appstarter` before announcing.

## Compatibility

- Existing `BaseComponent`, `data-on:event` directives, `component()` bare-default props,
  hash-router `add/subscribe/navigate` and `dv:*` events remain supported.
- Shared hosting remains supported: copy `dist/` or serve the source ESM files as-is; the CMS
  kit additionally needs PHP 8.2+ with `sqlite3` + `gd`.
- **Constitution links:** §10 (SemVer, changelog), §8.4 (pinning), §9.3 (budgets).
